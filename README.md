# ПРОФРАСЧЁТ — калькулятор материалов и услуг

Расчёт расхода материалов и стоимости услуг (доставка, подъём на этаж, распил) для сотрудников магазина.

- Сайт: https://profraschet-kalkulyator.vercel.app
- `index.html` — весь калькулятор (одна страница)
- `video/instrukciya.mp4` — видео-инструкция (открывается кнопкой «Видео» на сайте или по ссылке `#video`)
